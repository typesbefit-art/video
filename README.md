# Страшная и смешная история: генератор вертикального видео

Делает безлицевой ролик для TikTok, YouTube Shorts и Reels: MP4 1080x1920, H.264 + AAC, 50–65 с,
с озвучкой edge-tts, субтитрами по словам, фоном, звуковыми эффектами и финальной плашкой.

## Установка

```bash
pip install -r requirements.txt      # edge-tts, numpy, Pillow
# нужен ffmpeg: apt install ffmpeg  /  brew install ffmpeg  /  winget install ffmpeg
```

## Запуск

```bash
python generate.py story.txt              # -> output.mp4, 30 fps
python generate.py story.txt --fps 60     # 60 fps
python generate.py story.txt --preview 15 # пробная версия: первые 15 с -> preview.mp4
python generate.py story.txt -o my.mp4    # другое имя файла
python generate.py story.txt --seed 3     # другой случайный фон и шорохи
```

Озвучка кэшируется в `.cache/tts`: повторный запуск с тем же текстом и голосом не ходит в сеть.

## Как поменять историю

Отредактируйте `story.txt`. В **первой строке** заголовок (он озвучивается и 1,5 с висит на экране),
дальше текст. Код трогать не нужно.

Эффекты привязаны к фразам из раздела `cues` в `config.json`. Под новую историю впишите туда свои фразы:

| ключ         | что происходит |
|--------------|----------------|
| `light_on`   | на последнем слове фразы дрон резко обрывается, вспышка света |
| `red_glow`   | тонкий электронный писк, по краям пульсирует красное свечение |
| `joke_start` | пауза 1,0 с перед фразой, подсветка слов становится жёлтой |
| `joke_end`   | конец шутки: жёлтая подсветка выключается, свечение плавно становится зелёным |
| `relief`     | вступает лёгкая весёлая нота и подложка |
| `final`      | после фразы тихий финальный писк и резкая тишина |

Если фраза не нашлась, скрипт напишет предупреждение и просто пропустит этот эффект.

## Как поменять голос

`config.json`, раздел `voice`:

```json
"name": "ru-RU-DmitryNeural",   // ru-RU-SvetlanaNeural, ru-RU-DariyaNeural, en-US-GuyNeural…
"rate": "-4%",                  // темп речи
"pitch": "-3Hz",                // высота голоса
"sentence_pause": 0.4,          // пауза между предложениями, с
"joke_pause": 1.0               // пауза перед шуткой, с
```

Список всех голосов: `edge-tts --list-voices`. Если ролик выходит длиннее `duration.max` (65 с),
скрипт сам немного ускорит речь. Если короче `duration.min` (50 с), удлинит финал.

## Как поменять цвета и вид

`config.json`:
- `subtitles`: размер шрифта, высота на экране (`y_position`, 0.62 = 62 %), слов на экране (`max_words`),
  цвет текста и обводки, `highlight_color` (текущее слово, красный) и `joke_highlight_color` (в шутке, жёлтый);
- `title`, `outro`: заголовок и плашка «Часть 2? Подписывайся» (текст, цвет плашки, размер);
- `glow`: `scary_color` (красное свечение), `relief_color` (зелёное после шутки), `width` (ширина);
- `background`: цвета генерируемого градиента и тумана, `dim` (затемнение видеофона, 0.35 = 35 %);
- `audio`: громкость дрона (`drone_db`), голоса (`voice_db`) и минимальный запас голоса над музыкой.

Шрифт: `fonts/Inter-ExtraBold.otf` (лицензия OFL, `fonts/Inter-LICENSE.txt`). Если его нет, берётся DejaVu Sans Bold.

## Фоновые видео

Положите `.mp4` или `.mov` в папку `bg/`. Скрипт возьмёт случайный файл, зациклит его на длину ролика,
вырежет центральную вертикаль 9:16, затемнит на 35 % и добавит виньетку.
Если папка пуста, сгенерируется тёмный сине-фиолетовый градиент с медленным туманом.

## Как это устроено

1. Текст режется на предложения, каждое озвучивается через edge-tts вместе с событиями WordBoundary.
2. По краям фраз обрезается тишина, между ними вставляются точные паузы (0,4 с, перед шуткой 1,0 с).
3. Звук синтезируется в numpy: дрон 55 Гц с биениями, шорохи из полосового шума, писки и переборы-«пиццикато».
   Голос нормализуется до −14 dBFS, дрон до −28 dBFS, и скрипт проверяет, что голос громче фона минимум на 12 dB.
4. Кадры рисуются Pillow + numpy и потоком идут в ffmpeg (libx264 CRF 20, AAC 192k, `+faststart`).
