# Страшная история: генератор вертикальных роликов

Генератор делает безлицевое хоррор-видео для TikTok, YouTube Shorts и Reels: голос edge-tts, субтитры по словам, фон в стиле ночной камеры и звук, синтезированный с нуля.

```bash
python generate.py story.txt                       # -> output.mp4 (1080x1920, 30 fps)
python generate.py story.txt --fps 60              # 60 fps
python generate.py story.txt --duration 15 -o output_preview.mp4   # пробные 15 секунд
python generate.py story.txt --seed 42             # повторяемый результат (треск, фон)
```

Нужны Python 3.9+ и интернет (для edge-tts). Недостающие numpy, Pillow, edge-tts и ffmpeg скрипт ставит сам.
Озвучка кэшируется в `.cache/`, поэтому повторный запуск не ходит в сеть.

## Как менять

| Что | Где |
|---|---|
| **История** | `story.txt`: первая строка — заголовок, дальше текст. Реплика в «ёлочках» озвучивается вторым голосом шёпотом |
| **Голос** | `config.toml` → `[voice]`: `narrator`, `narrator_rate`, `narrator_pitch`, `quote_voice`, паузы. Список голосов: `edge-tts --list-voices` |
| **Цвета** | `config.toml` → `[colors]`: субтитры, активное слово, оттенок ночной камеры `night_tint`, REC, плашка |
| **Шрифт и субтитры** | `config.toml` → `[subtitles]`: размер, обводка, высота `y`, число слов, пульсация |
| **Эффекты** | `config.toml` → `[[events]]`: ключевые фразы для шкатулки, вспышки, зума, тишины, удара и финала |
| **Длительность** | `min_duration` и `max_duration`: паузы и темп подстраиваются автоматически |
| **Фоновые видео** | положи `.mp4`/`.mov` в папку `bg/`: возьмётся случайное, зациклится, обрежется до 9:16 и перекрасится |

Если фраза из `[[events]]` не найдена в новой истории, событие просто пропускается, а код при смене истории трогать не нужно.
