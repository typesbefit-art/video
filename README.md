# «Что если на Земле исчезнет свет?» — TikTok-видео, полностью из кода

Вертикальное видео 1080×1920, 30 fps, H.264 + AAC: 2D-мультяшная анимация, русская озвучка,
субтитры с подсветкой слов, синтезированные музыка и звуки. Внешних медиафайлов нет
(кроме шрифта Rubik, OFL, лежит в `assets/fonts/`).

**Почему Playwright + Canvas, а не Remotion:** весь пайплайн остаётся на Python (без Node-проекта и React),
а Canvas 2D в headless Chromium рисует кадр по функции `render(t)` детерминированно и быстро.

## Запуск

```bash
./run.sh preview   # быстрый предпросмотр 540x960 @ 15 fps → output/preview.mp4
./run.sh           # финальный рендер 1080x1920 @ 30 fps   → output/video.mp4
# или: make preview / make
```

Нужны Python 3.10+, ffmpeg и интернет (edge-tts). Python-зависимости (`requirements.txt`)
и Chromium для Playwright `run.sh` поставит сам.

## Как это устроено

| Файл | Что делает |
|---|---|
| `script.json` | сцены: текст озвучки, модуль сцены, «биты» (смены кадра внутри сцены), звуковые эффекты |
| `tts.py` | edge-tts (`ru-RU-DmitryNeural`, запасной `ru-RU-SvetlanaNeural`), тайминги слов → `build/voice.wav`, `build/timeline.json` |
| `audio.py` | синтез на numpy: эмбиент, нарастающий к концу, + пуф / хлопок / свист / бульк / «вжух» → `build/music.wav`, `build/sfx.wav` |
| `render.py` | собирает `build/page.html` из `scenes/*.js` и рендерит кадры в Chromium (параллельно) → `build/video_*.mp4` |
| `build.py` | ffmpeg: видео + голос + музыка (приглушается под голос) + эффекты, громкость −14 LUFS, проверка через ffprobe |
| `scenes/lib.js` | easing, палитра тепло→холод, камера, примитивы с жирным контуром, персонажи (Лучик, люди, звери…) |
| `scenes/engine.js` | таймлайн: переходы между сценами, «пинки» камеры на битах, цветовой грейд, субтитры |
| `scenes/0X_*.js` | по модулю на сцену: `SCENES.<id> = { render(ctx, t, env) }` |

**Синхронизация.** Длительность каждой сцены = реальная длина её озвучки + пауза. Все события
(смена кадра, «пуф», появление «−70°C», подмигивание) привязаны к словам, а не к секундам:
в `script.json` пишется `"at": "исчезнет"` (или `"растения#2"` — второе вхождение), в сцене —
`env.w('исчезнет')`. Поменяли текст или скорость — всё пересчитается само.

## Как менять

- **Текст** — правьте `text` в `script.json`. Если удалили слово, на которое ссылаются `beats`/`sfx`
  или `env.w(...)` в сцене, замените ссылку. Озвучка кэшируется по предложениям в `build/tts/`.
- **Голос / темп** — `voice`, `rate` (например `"+10%"`), `pitch` в `script.json`.
- **Палитра** — функция `PAL(p)` в `scenes/lib.js` (p = 0 начало видео … 1 конец).
- **Субтитры** — `SUB_Y`, `SUB_SIZE`, цвет подсветки `#ffd23f` в `scenes/engine.js`; разбиение
  на группы по 2–4 слова — `make_groups()` в `tts.py`.
- **Контуры / персонажи** — `INK`, `OUT` и функции `luchik()`, `person()` и др. в `scenes/lib.js`.
- **Музыка и звуки** — `music()` и `sfx_*()` в `audio.py`; громкость слоёв — фильтр в `build.py`.
- **Проверить отдельные кадры**: `python3 render.py --preview --still 2 10.5 30` → `build/stills/`.
