# Анимированная аватарка

| Файл | Что это |
|---|---|
| `avatar.svg` | исходник (круглый, с clipPath и контуром) |
| `avatar_square.svg` | генерируется: квадрат 380×380, без клипа и контура, все анимации кратны 6 с |
| `avatar.mp4` | Telegram: 800×800, 6 с, 30 fps, H.264, yuv420p, без звука, faststart, ≤ 2 МБ |
| `avatar.png` | WhatsApp: статичный кадр 640×640 (момент 1.5 с) |
| `render.py` | весь пайплайн |

## Перезапуск

```bash
pip install playwright pillow numpy   # numpy не обязателен
python3 -m playwright install chromium  # если Chromium ещё нет
# нужен ffmpeg/ffprobe с libx264
python3 render.py                       # или: --src другой.svg  --keep-frames
```

Что делает скрипт:

1. Из `avatar.svg` получает `avatar_square.svg`: убирает `<clipPath>`, `clip-path` и `circle` со `stroke`,
   приводит длительности анимаций к делителям 6 с
   (5→6, 7→6, 0.7→0.75, 0.9→1, 1.1→1.5, 3.4→3, 2.6→3, остальные к ближайшему из 6/3/2/1.5/1/0.75/0.6),
   масштабирует задержки и делает их отрицательными, чтобы на нулевом кадре не было «неанимированного» состояния.
2. Открывает SVG в Chromium (viewport 800×800), ставит все `document.getAnimations()` на паузу и для кадра `i`
   выставляет `currentTime = i/30*1000`, затем делает скриншот. Рендер детерминированный, без записи экрана.
3. Проверяет шов: кадр 0 должен совпадать с кадром на t = 6000 мс.
4. Собирает видео через ffmpeg, начиная с CRF 22; если файл больше 2 МБ, повышает CRF.
5. Сохраняет `avatar.png` и выводит отчёт ffprobe.

Последний прогон: CRF 22 → 279 КБ, h264 800×800 yuv420p, 30 fps, 180 кадров, 6.000 с, звука нет.

## Как поставить

**Telegram:** Настройки → Изменить профиль → Установить фото → выбрать `avatar.mp4`.
Telegram сам обрежет квадрат в круг, лицо стоит по центру.

**WhatsApp:** Настройки → нажать на фото профиля → Изменить → выбрать `avatar.png`.
