# Что, если наступит ядерная война — вертикальное видео (Reels / Shorts)

Проект на **Remotion (React + TypeScript)**: 1080×1920, 30 fps, длина по озвучке (1648 кадров ≈ 54.9 сек).
Вся графика нарисована кодом (SVG/CSS) в стиле «2D реализм»: параллакс в 3–5 слоёв, медленный наезд камеры (Ken Burns),
тряска от ударной волны, пепел, дым, снег, мерцание света, плёночное зерно, виньетка, холодная цветокоррекция.

## Быстрый старт

```bash
npm install
# 1. положите озвучку:            public/voiceover.mp3
npm run align     # 2. уточнить тайминги сцен по паузам в озвучке
npm run dev       # 3. превью в Remotion Studio (http://localhost:3000)
npm run render    # 4. итоговое видео → out/video.mp4 (H.264 + AAC)
```

Нужны Node.js 18+ и `ffmpeg`/`ffprobe` в PATH (для `npm run align`).

## 1. Куда положить озвучку

Файл из ElevenLabs кладётся в **`public/voiceover.mp3`**. Команды `dev`, `align` и `render` сначала проверяют,
есть ли файл, и если его нет, останавливаются с напоминанием.

## 2. Тайминги

- **`scenes.json`**: 8 сцен (`start`/`end` в секундах, `text` из озвучки, `title` для экрана, `image` для своей иллюстрации).
  Каждая сцена начинается ровно на своём `start`. Следующая сцена проявляется поверх предыдущей за 12 кадров.
- **`script.txt`**: полный текст озвучки (абзац = сцена; последняя фраза «Подпишись…» входит в финальную сцену).

### Пересчёт таймингов: `npm run align`

`scripts/align.ts`:
1. через `ffprobe` узнаёт длительность и обновляет `durationInFrames`;
2. запускает `ffmpeg -i public/voiceover.mp3 -af silencedetect=noise=-35dB:d=0.3 -f null -`;
3. сдвигает каждую границу между сценами к ближайшей паузе в пределах **±1.5 сек**. Граница ставится
   за 0.12 сек до того, как снова вступает голос. Если паузы рядом нет, граница остаётся как была;
4. сохраняет для каждой сцены отрезки речи (`speech`). По ним раскладываются субтитры;
5. если установлен **faster-whisper** (python) или **openai-whisper** (CLI `whisper`), берёт из него
   тайминги слов и пишет их в `words.json`. Скрипт ничего не устанавливает сам. Модель можно выбрать
   так: `WHISPER_MODEL=medium npm run align`. Отключить Whisper: `npm run align -- --no-whisper`.

Стартовые значения сохраняются в поле `draft` каждой сцены, поэтому повторный запуск всегда считает от них.
Чтобы поправить сцену вручную, меняйте `draft.start`/`draft.end` и перезапускайте `align`
(или правьте `start`/`end`, если `align` больше запускать не будете).

### Субтитры

- Если в `words.json` есть слова от Whisper, используются они (текст берётся из сценария, время из Whisper).
- **Запасной вариант:** слова сцены распределяются пропорционально длине (числу символов) между началом и концом речи.
  Если число отрезков речи совпадает с числом предложений, каждое предложение кладётся в свой отрезок,
  иначе паузы просто пропускаются.
- На экране по 2–4 слова, белый текст с тёмной обводкой. Слова **ядерная, вспышка, голод, зима, десятилетия**
  подсвечиваются жёлтым.
- Безопасная зона: 150 px сверху, 250 px снизу. Субтитры стоят на 440 px от низа, заголовки начинаются ниже 150 px.
  Проверить в Studio: в правой панели props включите `showSafeZone`, и появится рамка зоны.

Анимации внутри сцен тоже привязаны к словам (`wordFrame()` в `src/lib/timing.ts`): вспышка на «Ослепительная»,
ударная волна на «ударная», иконки гаснут на «свет / связь / интернет», термометр на «температура»,
надписи «ЯДЕРНАЯ ЗИМА», «ГОЛОД», «ДЕСЯТИЛЕТИЯ» и кнопка «ПОДПИШИСЬ» на своих словах.

## 3. Рендер

```bash
npm run render          # → out/video.mp4, H.264 (yuv420p, CRF 18) + AAC
```

Если Remotion не может скачать свой Chrome Headless Shell (нет сети или прокси), укажите локальный браузер:

```bash
REMOTION_BROWSER=/path/to/chrome-headless-shell npm run render
```

Шрифт Montserrat (с кириллицей) берётся из `node_modules/@fontsource`, сеть при рендере не нужна.

## Структура

```
public/voiceover.mp3          ← озвучка (кладёте вы)
public/illustrations/         ← плейсхолдеры для своих иллюстраций (см. README внутри)
scenes.json                   ← тайминги и тексты сцен
words.json                    ← тайминги слов от Whisper (пусто = запасной вариант)
script.txt                    ← текст озвучки
scripts/align.ts              ← уточнение таймингов (ffmpeg silencedetect [+ Whisper])
scripts/check-audio.ts        ← проверка наличия озвучки
src/Root.tsx, src/Video.tsx   ← композиция «Main», аудио, сцены, субтитры, плёночный слой
src/components/
  Scene.tsx                   ← обёртка сцены: кроссфейд, цветокоррекция, плейсхолдер картинки
  Parallax.tsx                ← камера + слои с глубиной, тряска
  Particles.tsx               ← пепел, снег, искры, дым, пыль, обломки
  Subtitles.tsx               ← субтитры в стиле Shorts + рамка безопасной зоны
  Title.tsx                   ← заголовки и плашки эпизодов
  Effects.tsx                 ← зерно, виньетка, цветокоррекция, царапины плёнки
  art.tsx                     ← процедурная графика: небо, солнце, горы, город, облака, поле, ЛЭП…
src/scenes/S1Hook … S8Final   ← 8 сцен
src/lib/timing.ts             ← тайминги, раскладка слов, группы субтитров, wordFrame()
```

## Свои иллюстрации

Укажите `"image": "illustrations/<id>.png"` у сцены в `scenes.json`. Картинка заменит процедурный фон,
а частицы, надписи и эффекты останутся поверх неё. Подробности в `public/illustrations/README.md`.
