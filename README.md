# Страшная история: генератор вертикальных роликов (серия «Видеоняня»)

Генератор делает безлицевое хоррор-видео для TikTok, YouTube Shorts и Reels: голос edge-tts, субтитры по словам, фон в стиле ночной камеры и звук, синтезированный с нуля.

```bash
python generate.py story.txt                 # часть 1 -> output.mp4
python generate.py story2.txt part2          # часть 2 -> output_part2.mp4 (настройки parts/part2.toml)
python generate.py story3.txt part3          # часть 3 -> output_part3.mp4 (настройки parts/part3.toml)

python generate.py story2.txt part2 --duration 15 -o output_part2_preview.mp4   # пробные 15 секунд
python generate.py story.txt --fps 60        # 60 fps
python generate.py story.txt --seed 42       # повторяемый результат (треск, зерно)
```

Нужны Python 3.9+ и интернет (для edge-tts). Недостающие numpy, Pillow, edge-tts и ffmpeg скрипт ставит сам.
Озвучка кэшируется в `.cache/tts/`, поэтому повторный запуск не ходит в сеть.

## Своя озвучка вместо edge-tts

Текст для записи с номерами фраз лежит в `СЦЕНАРИЙ_ОЗВУЧКИ.md`. Записи кладутся в папку `voice/`:

```
voice/part1/01.wav … 21.wav     ← по файлу на фразу (лучший вариант)
voice/part2/01.wav … 25.wav
voice/part3/01.wav … 22.wav
или voice/part1.wav, voice/part2.wav, voice/part3.wav  ← одним файлом, паузы между фразами от 1 с
```

Если запись нашлась, генератор берёт её вместо edge-tts: подрезает тишину, выравнивает громкость, добавляет шёпот репликам и сам считает тайминги слов для субтитров. Запуск тот же:
`python generate.py story.txt` (часть 1 ищет `voice/part1`), `python generate.py story2.txt part2`, `python generate.py story3.txt part3`.

## Как устроены настройки

- `config.toml` — общий стиль серии: голоса, цвета, шрифт, субтитры, громкость, зерно и виньетка. Здесь же события части 1.
- `parts/<имя>.toml` — только то, что отличается в конкретной части: таймкод, текст плашки, особые паузы, события.
  Таблицы сливаются с `config.toml`, а список `[[events]]` заменяется целиком.

## Как менять

| Что | Где |
|---|---|
| **Текст** | `storyN.txt`: первая строка — заголовок. Реплика в «ёлочках» озвучивается вторым голосом шёпотом. Слова автора внутри реплики («Лена, — сказала она. — …») читает рассказчик |
| **Кавычки, которые читает рассказчик** | `[voice] narrator_quotes` в файле части: надписи на экране, названия устройств, реплики самого рассказчика |
| **Голос** | `[voice]`: `narrator`, `narrator_rate`, `narrator_pitch`, `quote_voice`, `quote_rate`, `quote_whisper`, паузы. Особые паузы задаются так: `pause_before = [{ phrase = "…", pause = 1.3 }]`. Список голосов: `edge-tts --list-voices` |
| **Цвета** | `[colors]`: субтитры, активное слово, ночной оттенок `night_tint`, дневной `day_tint`, REC, плашка. Карточка приложения — `[card]` в `parts/part2.toml` |
| **Названия устройств** | `parts/part2.toml`, событие `type = "card"`: `title`, `rows = [{ name = "Лена", style = "alert", reveal = "Лена" }]` (`style` бывает `muted` — серая или `alert` — красная рамка; `reveal` — на какой фразе строка появляется), `note`, `status` |
| **Таймкод и подпись камеры** | `[video] timecode_start`, `cam_label`; скачки времени — событие `timecode` |
| **Длительность** | `[video] min_duration` и `max_duration`: паузы, а при необходимости и темп, подстраиваются автоматически |
| **Фоновые видео** | положи `.mp4`/`.mov` в папку `bg/`: возьмётся случайное, зациклится, обрежется до 9:16 и перекрасится |

## События (`[[events]]`)

Фразы ищутся в озвученном тексте без учёта регистра и «ё». Слово можно указывать основой: «колыбельн».
Если фраза не найдена, событие просто пропускается.

| type | Что делает |
|---|---|
| `music_box` | шкатулка с `start` до `stop`; `clean = true` — чистая, без динамика няни |
| `hum` | низкий гул 35–50 Гц с нарастанием; обрывается на `stop` или в начале тишины |
| `silence` | резкая тишина: `at = "after"`, `"before"` или `"start"`; `duration` — число или `"end"` |
| `hit` | низкий удар |
| `ghost` | фигура: `kind = "woman"` или `"tall"`, `camera`, `x`, `y`, `height`, `dark`, `flicker`, `grow_to`, `grow_until`, `show` и `hide` (`"@start"` — с начала ролика) |
| `flash` | мерцание и белый силуэт на слове |
| `light` | засветка камеры и щелчок |
| `zoom` | плавный зум |
| `camera` | переключение на CAM 02 (вид сверху) |
| `day` | дневной режим камеры с `start` до `stop` |
| `timecode` | скачок таймкода; `anchor` — на какой фразе должно быть `value` |
| `card` | карточка приложения со списком устройств |
| `shake` | дрожание кадра до конца |
| `white_frame` | один белый кадр |
| `ending` | с этой фразы начинаются помехи и затемнение |
