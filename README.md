# Тут все оттуда

Мультфильм примерно на 60 секунд в одном файле `index.html`: SVG + CSS-анимации, озвучка через Web Speech API (ru-RU). Внешних библиотек нет.

Откройте `index.html` в браузере (лучше Chrome или Edge с русским голосом) и нажмите «▶ Старт». Пауза ставится кнопкой или пробелом.

Параметры для отладки: `?mute=1` (без звука), `?speed=6` (ускорение, звук выключается), `?scene=5` (начать с 5-й сцены).

## Видео

Готовая запись лежит в `tut-vse-ottuda.mp4`: 1280×720, 25 кадров/с, озвучка синтезатором espeak-ng.

Как пересобрать (нужны Playwright с Chromium, ffmpeg и espeak-ng):

```
node tools/record-video.js /tmp/rec tut-vse-ottuda.mp4
```

Скрипт берёт фразы из массива `scenes`, озвучивает их через espeak-ng, записывает мультфильм из браузера и сводит видео со звуком через ffmpeg.
