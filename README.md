# Анимированная аватарка «парень под дождём»

| Файл | Что это |
|---|---|
| `avatar.mp4` | 800×800, 6 с, 30 fps, H.264 High, yuv420p, без звука, faststart, ~300 КБ |
| `avatar.png` | статичный кадр 640×640 (WhatsApp / запасной вариант) |
| `avatar.svg` | исходник, подготовленный для квадрата и бесшовного 6-секундного цикла |
| `avatar_original.svg` | исходный SVG без изменений |
| `render.js` | рендер кадр за кадром (Playwright + ffmpeg) |

## Перезапуск

Нужны Node.js, пакет `playwright` с Chromium (`npm i playwright && npx playwright install chromium`) и `ffmpeg` в PATH.

```sh
node render.js              # CRF 22, кадр для PNG на 1.0 с
node render.js --crf 26     # если mp4 больше 2 МБ
node render.js --png-time 3 # другой кадр для avatar.png
```

Скрипт открывает SVG в Chromium (viewport 800×800), ставит все анимации на паузу и для каждого
кадра `f` задаёт `animation.currentTime = f / 30 * 1000` через `document.getAnimations()`.
Рендерятся кадры 0–179 (кадр 180 совпадает с кадром 0), затем ffmpeg собирает mp4.

## Что изменено в SVG

- Убраны `clipPath` и внешний круглый контур: фон `#0A1224` заполняет весь квадрат, Telegram обрежет в круг сам.
- Все периоды делят 6 с нацело: голова 5→6 с, волосы 6 с, вспышка 7→6 с (один раз за цикл, ≈5.4 с),
  дождь 0.7/0.9/1.1→0.75/1/1.2 с, капли по лицу 3.4→3 с, капля на подбородке 2.6→3 с.
- У второй капли задержка `1.7s` → `-1.5s`. С положительной задержкой первые 1.7 с она висела
  неподвижно, и в начале цикла был бы шов.

## Как поставить в Telegram

Настройки → Изменить профиль → Установить фото → выбрать `avatar.mp4`.
