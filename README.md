# Страшная и смешная история — генератор вертикальных видео

Безлицевой ролик 1080×1920 (H.264 + AAC) для TikTok / Shorts / Reels: озвучка edge-tts,
пословные субтитры, сгенерированные звуки и эффекты.

## Установка
```bash
pip install -r requirements.txt     # edge-tts, Pillow, numpy, scipy, certifi
# нужен ffmpeg: sudo apt install ffmpeg  /  brew install ffmpeg
```

## Запуск
```bash
python generate.py story.txt                    # → output.mp4, 30 fps
python generate.py story.txt --fps 60           # 60 fps
python generate.py story.txt --limit 15 -o preview_15s.mp4   # пробные 15 секунд
python generate.py story.txt -o other.mp4 --config my.json   # другой выход/конфиг
```
Озвучка кэшируется в `.cache/tts/`, повторный запуск не обращается к сети.
Если edge-tts отвечает «No audio received», скрипт сам повторяет запрос с паузой.

## Как менять
| Что | Где |
|---|---|
| История | `story.txt`: 1-я строка — заголовок, дальше текст. Реплики — в «ёлочках». |
| Кто призрак | `config.json → ghost.markers`: цитата считается репликой призрака, если в части предложения перед ней есть одно из этих слов («Он сказал: «…»»). |
| Голос | `voice.name` (список: `edge-tts --list-voices`), `voice.rate` (%), `voice.pitch` (Hz). `mood_drift`: голос плавно замедляется к концу (растерянность); `"enabled": false` отключает. |
| Паузы | `pauses.default` — между фразами; `pauses.before` — особые паузы перед фразой (по началу фразы). |
| Цвета | `colors`: текст, обводка, подсветка (`highlight`), подсветка призрака (`ghost_highlight`), плашка, цвета градиента и тумана. |
| Субтитры | `subtitles`: шрифт, размер, обводка, высота (`y` = 0.62), КАПС, слов в группе. |
| Звуки / эффекты | `sfx` и `vfx`: `match` — слово (по началу, `"прозрачн"`), фраза (`"даже я готовил лучше"`) или `"@last:2"` (2-е слово с конца). Типы звуков: `chair`, `whoosh`, `slurp`, `vanish`; эффекты: `flicker`, `dim`. Можно добавить `offset` и `gain_db`. Если триггер не найден, он просто пропускается. |
| Громкость | `audio.drone_db` (−28), `audio.voice_rms_db`, `min_voice_over_music_db` (12). |

## Фоновые видео
Положите `.mp4` / `.mov` в папку `bg/` рядом со скриптом. Берётся случайный файл,
зацикливается под длину ролика, обрезается по центру до 9:16, затемняется на 35%
и подкрашивается в холодный синий. Если папка пустая или её нет, фон генерируется:
сине-зелёный градиент, туман, редкие вспышки.
