# Видео-переписка для Shorts / TikTok / Reels

Генерирует вертикальное видео (1080x1920, 60 fps, H.264 + AAC) в виде фейковой переписки
в мессенджере с озвучкой, субтитрами, звуками и фоновым битом.

```bash
pip install -r requirements.txt     # Pillow, numpy, edge-tts
# нужен ffmpeg: apt install ffmpeg / brew install ffmpeg

python generate.py script.json                         # -> output.mp4
python generate.py script.json --limit 6 -o preview.mp4  # пробная версия, первые 6 реплик
python generate.py script.json --frame 12.5             # один кадр в PNG для проверки вёрстки
```

Опции: `-o` имя файла, `--limit N` первые N реплик, `--no-fit` не подгонять под 45–60 с,
`--workers N` число процессов рендера.

## Сценарий — `script.json`

Код при смене сюжета не трогаем, всё здесь:

```json
{
  "title": "Когда подруга сказала «буду через 5 минут»",
  "outro": "Подписывайся на «Прочитано и проигнорировано»",
  "start_time": "19:42",
  "characters": { "lera": {...}, "yana": {...} },
  "messages": [
    {"who": "lera", "text": "Ты где?", "pause_after": 0.3},
    {"who": "yana", "text": "...да", "tts": "...да.", "pause_after": 0.5}
  ]
}
```

- `title`: заголовок-крючок на первую секунду; текст в «ёлочках» подсвечивается жёлтым.
- `outro`: плашка на последние 1,5 с; часть в «ёлочках» станет крупным названием.
- `messages[].pause_after`: пауза после реплики (сек). `tts` (необязательно): что произнести,
  если надо иначе, чем написано (ударение, цифры словами и т. п.).
- Можно передать и просто массив реплик: тогда персонажи берутся по умолчанию.

Если ролик выходит длиннее 60 с, скрипт сначала сокращает паузы, а потом ускоряет речь
шагами по 4%. Если короче 45 с, растягивает паузы.

## Персонажи: имена, голоса, цвета

Блок `characters` в `script.json`:

```json
"lera": {
  "name": "Лера",              // имя (в шапке, в плашке субтитров, буква на аватарке)
  "side": "right",             // right = «я» (фиолетовые пузыри, галочки), left = собеседница в шапке
  "voice": "ru-RU-SvetlanaNeural",
  "pitch": "-2Hz",             // высота голоса
  "rate": "+0%",               // темп речи
  "bubble": ["#8B5CF6", "#6D28D9"],  // градиент пузыря (или одна строка-цвет)
  "avatar": "#7C3AED"          // цвет аватарки и плашки с именем
}
```

Список голосов: `edge-tts --list-voices`. Для русского в edge-tts есть только
`ru-RU-SvetlanaNeural` (жен.) и `ru-RU-DmitryNeural` (муж.). Многоязычные голоса
(`en-US-AvaMultilingualNeural`, `en-US-EmmaMultilingualNeural`,
`fr-FR-VivienneMultilingualNeural`) тоже читают по-русски. Тембр у них по-настоящему другой,
но может быть слышен лёгкий акцент. Попробуйте один из них для Яны.

Озвучка кэшируется в `.cache/tts/`, поэтому повторный запуск с тем же текстом проходит быстро.

## Оформление

Общие цвета (фон, подсветка субтитров, галочки, плашка подписки) лежат в словаре `THEME`
в начале `generate.py`. Там же размеры, тайминги анимаций и громкости
(`POP_GAIN`, `BEAT_GAIN`, `BEAT_DUCK`).

Шрифт: Inter (SIL OFL, лежит в `fonts/`).
