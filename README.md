# Хоррор-шортс: «страшная история с озвучкой и субтитрами»

Генерирует вертикальное безлицевое видео для TikTok / YouTube Shorts / Reels:
MP4 1080×1920, H.264 + AAC, 30 fps (или 60), 50–65 секунд.

```bash
pip install -r requirements.txt      # edge-tts, numpy, pillow (+ нужен ffmpeg в PATH)
python generate.py story.txt         # → output.mp4
python generate.py story.txt --fps 60
python generate.py story.txt --preview 15   # пробная версия: первые 15 с → preview.mp4
```

Прочие флаги: `-o файл.mp4`, `--bg папка`, `--seed N` (другой рисунок фона/звука и
другой случайный ролик из bg/), `--workers N`, `--keep-temp`.

## Серия: части 2 и 3

```bash
python generate.py story2.txt part2     # → output_part2.mp4  («Ночная смена. Рация»)
python generate.py story3.txt part3     # → output_part3.mp4  («Ночная смена. Счёт»)
python generate.py story2.txt part2 --preview 15   # пробные 15 с → preview_part2.mp4
```

Второй аргумент — сценарий части: `parts/part2.json` накладывается поверх `config.json`.
В сценарии заданы голоса персонажей, правила реплик, таймкод, начальное значение счётчика,
стиль субтитров и заголовка, а также список эффектов с привязкой к фразам из текста.

**Реплики.** Текст в «ёлочках» озвучивается голосом персонажа, если подходит под правило
из `dialogue`: `{"starts": "Не выходи", "speaker": "semyon"}` (начало реплики) или
`{"exact": "Один", "speaker": "guard"}` (точное совпадение). Остальные кавычки читает
рассказчик. Голос персонажа задаётся в `speakers`: `name`, `rate`, `pitch`, `fx`. Значение
`"fx": "radio"` даёт эффект рации: полосу 300–3000 Гц, перегруз, шипение, щелчок кнопки
перед репликой и «хвост» эфира после неё.

**Таймкод.** `clock.start` задаёт время на первом кадре. `clock.jumps` — резкий прыжок
на слове, при `"glitch": 0.7` с RGB-глитчем. `clock.ramps` — ускоренная перемотка между
двумя фразами.

**Счётчик.** `counter.initial` задаёт стартовое число, `counter.alert_at` — порог, с которого
число и рамка красные (214). `counter.alert_after` делает их красными после указанной фразы.

**Эффекты** (`effects`, у каждого есть `phrase` — фраза из текста; `@last` означает
последнее предложение; `"occurrence": "last"` — последнее вхождение фразы):

| type | что делает |
|---|---|
| `cam_interference` | ячейка `cam` мерцает и даёт помехи (на время фразы или `duration`) |
| `radio_hiss` | всплеск шипения рации |
| `corridor_crowd` | в ячейке `cam` проявляются ряды неподвижных силуэтов (`fade` секунд); `initial` — видны с начала, `vanish_phrase` — исчезают |
| `counter_set` | счётчик меняется на `value`; `flash` — вспышка рамки, `shake` — дрожание кадра |
| `hum_cut` | гул обрывается, остаётся низкий тон `tone_hz` |
| `doors_open` | в ячейке `cam` (ВХОД) распахиваются двери, кадр светлеет и холодеет |
| `count_out` | счёт вслух: счётчик убывает от `start`, щелчки, люди выходят в двери, Семён останавливается, оборачивается и уходит |
| `freeze` | все ячейки замирают на `duration` секунд |
| `silence_before` | полная тишина `seconds` секунд перед фразой |
| `shake` | дрожание кадра |
| `zoom_cam` | ячейка `cam` увеличивается на весь экран, в конце коридора стоит силуэт |
| `drone` | тихий низкий гул до конца |
| `final_static` | финальные помехи перед затемнением |

**Названия камер.** `cameras` в `config.json` или в сценарии части:
`["CAM 01", "ВХОД", "entrance"]`. Третье поле — тип сцены: `entrance`, `corridor`,
`hall`, `parking`, `service`, `food`.

**Финал.** Блок `end`: `gap`, `fade` (красные края и уход в чёрное) и `card` (секунды
плашки на чёрном). Текст плашки — `text.end_card`, первая строка красная, вторая белая.

## Что внутри

| Слой | Как сделано |
|---|---|
| Голос | edge-tts `ru-RU-DmitryNeural`, каждое предложение озвучивается отдельно, поэтому паузы точные (0,5 с; 1,2 с перед «И я понял…»; 1,5 с перед последним предложением). Тайминги слов берутся из событий WordBoundary. Ответы кэшируются в `.cache/tts/`. |
| Длина | Если ролик выходит длиннее `duration.max`, темп нарастает к финалу (рассказчик теряет самообладание): старт ровно с `rate`, потолок `max_rate`. Если и этого мало, обычные паузы ужимаются до `min_pause`. |
| Субтитры | Inter ExtraBold (запасной вариант DejaVu Sans Bold), белые с чёрной обводкой, по 3–4 слова, центр на 62% высоты, текущее слово красное с пульсацией. |
| Счётчик | «ВНУТРИ: N» в левом верхнем углу появляется на фразе `counter_start` и меняется вместе с озвучкой. На большом скачке (5 → 214) идёт ускоряющаяся очередь щелчков. |
| Фон | Ролик из `bg/` или сгенерированные мониторы охраны (сетка 2×3). |
| Звук | Всё синтезируется в numpy: гул вентиляции (−30 dB), далёкие шаги, щелчки турникета, шёпот толпы, удар. На `silence_at` всё резко стихает. Голос громче фона минимум на 12 dB, скрипт проверяет и печатает разницу. |
| Эффекты | Заголовок 1,5 с, мигание мониторов, один кадр с силуэтами, красное свечение и затемнение в последние 3 с, плашка «Часть 2? Подписывайся» на 1,5 с. |

## Как менять

**Историю.** Правьте `story.txt`: первая строка — заголовок, дальше текст. Паузу можно
поставить прямо в тексте маркером `[пауза 1.2]` перед предложением. Эффекты привязаны
к фразам в `config.json → cues`. Если в новой истории другие ключевые фразы,
поменяйте их там. Фразу, которой нет в тексте, скрипт пропустит и предупредит.

- `clicks_from`: с этого места каждое числительное даёт щелчок турникета;
- `counter_start`: появление счётчика; `counter_label`: подпись;
- `silence_at`: всё стихает; `monitors_flicker`: мигание мониторов;
- `silhouettes`: кадр с силуэтами; `crowd`: шёпот толпы и удар.

Если в тексте есть время вида `3:07`, часы на мониторах синхронизируются с ним сами.

**Голос.** `config.json → voice`: `name` (например `ru-RU-SvetlanaNeural`; список
голосов выводит `edge-tts --list-voices`), `rate` и `pitch` (стартовый темп и тон),
`tension_ramp` и `max_rate` (насколько ускоряется речь к финалу), `pause`,
`pause_before_last`, `pause_before`. Если нужен строгий темп без подгонки длины,
поставьте `"duration": {"fit": "none"}`.

**Цвета.** `config.json → colors`: `subtitle`, `stroke`, `highlight` (текущее слово),
`counter`, `counter_alert`, `edge_glow` (финальное свечение), `monitor_tint`
(множители RGB для мониторов), `hud`, `bg_video_tint` (множители RGB для фонового
видео; среднее ≈ 0,65 даёт −35% яркости).

**Громкость.** `config.json → audio` (значения в dBFS).

**Фоновые видео.** Положите `.mp4` или `.mov` в папку `bg/` рядом с `generate.py`.
Скрипт возьмёт случайный файл, зациклит его под длину ролика, вырежет центральную
вертикаль 9:16, перекрасит в холодную серо-синюю гамму, приглушит на 35% и добавит
зерно камер наблюдения. Если папка пустая, сгенерирует мониторы охраны.
