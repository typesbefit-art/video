# Три невидимые утечки — автоматический 2D-мультфильм для Shorts / Reels

Одна команда собирает вертикальный мультфильм с озвучкой:

```bash
npm install
pip install edge-tts
npm run build        # → out/video.mp4 + out/preview/*.png
```

Выход: `out/video.mp4`, 1080×1920, 60 fps, 58–60 с, H.264 High CRF 18 yuv420p, AAC 48 кГц, `+faststart`.

## Что нужно установить

- Node.js 18+ и npm
- Python 3.9+ и `pip install edge-tts`
- ffmpeg и ffprobe в `PATH`
- Chrome для Remotion скачивается сам. Если в системе уже есть Chrome Headless Shell, укажите его в `REMOTION_BROWSER_EXECUTABLE` (Playwright-сборка в `/opt/pw-browsers` подхватывается автоматически).
- Интернет нужен только при первой генерации озвучки: edge-tts обращается к `speech.platform.bing.com`. Готовое аудио кэшируется в `tts/`.

## Как это работает (`scripts/build.mjs`)

1. **Озвучка**: `scripts/tts.py` озвучивает каждую реплику из `script.json` через edge-tts и сохраняет `tts/<scene>_<hash>.mp3`, тайминги слов WordBoundary (`*.words.json`) и `tts/manifest.json`. Кэш привязан к хэшу текста и настроек голоса: меняете текст или голос, и перегенерируются только изменённые реплики.
2. **Таймлайн** (`scripts/timeline.mjs`): длительность сцен берётся из реальной длины аудио. Если сумма больше `maxDurationSec`, скрипт сам ускоряет голос (`autoAdjustRate`) и озвучивает заново. Если меньше `minDurationSec`, добавляются паузы в конце сцен. Каждая сцена режется на планы по 3–5 с, склейки ставятся перед словом. Субтитры собираются в группы до 3 слов.
3. **Звук** (`scripts/audio.mjs`): озвучка на 100 %. Whoosh (шум через полосовой фильтр с плавающей частотой) и звон монеты (негармонические обертоны с затуханием) синтезируются кодом и подмешиваются на −18 dB. Музыка добавляется только если в `assets/music/` лежит файл (на −24 dB, с фейдами). В конце мягкий лимитер на −1 dBFS. Тот же сигнал даёт RMS-огибающую по кадрам для липсинка.
4. **Рендер**: Remotion (React + SVG) рендерит видео без звука в промежуточный H.264 CRF 10.
5. **Сборка**: ffmpeg перекодирует в итоговый H.264 CRF 18 yuv420p, добавляет AAC 48 кГц и `+faststart`.
6. **Проверка** (`scripts/verify.mjs`): ffprobe проверяет разрешение, fps, длительность, кодеки, наличие аудио и faststart, плюс замеряет громкость. Сохраняет 3 превью (начало, середина, конец) в `out/preview/` и копии с наложенной безопасной зоной (`*_safezone.png`).

## Структура

```
script.json          тексты, голос, подписи на экране, параметры тайминга (меняется только он)
tts/                 сгенерированная озвучка + тайминги слов (кэш)
src/                 Remotion: Video.tsx, scenes/, characters/ (Max, Coin), backgrounds, props, Subtitles, Headline
scripts/             пайплайн сборки, TTS, звук, проверка, stills.mjs (рендер отдельных кадров для отладки)
assets/music/        положите сюда трек, если нужна фоновая музыка
out/                 video.mp4, preview/, timeline.json
```

## Как изменить

- **Голос**: `script.json → voice.name` (например `ru-RU-SvetlanaNeural`), `rate`, `pitch`. У отдельной реплики можно задать свой `"voice": {...}`.
- **Текст**: `scenes[].lines[].text`, кто говорит: `speaker: "max" | "coin"` (от этого зависит, чей рот двигается, и цвет подсветки слова).
- **Подписи на экране**: `scenes[].labels`.
- `npm run studio` открывает Remotion Studio для предпросмотра. `npm run timeline` пересчитывает таймлайн и звук без рендера.
